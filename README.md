# NightDeck — Project 2 / 6

Ambient bedside lock screen: AMOLED clock, sleep sound mixer, bedtime reminders, real home-screen widget. Flutter/Dart.

## What YOU need to add locally
1. **Generate the platform folders** — this project only ships `lib/` and `pubspec.yaml`. From inside `NightDeck/`, run:
   ```
   flutter create --project-name nightdeck --org com.nightdeck .
   ```
   This generates `android/`, `ios/`, `.dart_tool/`, `.gitignore`, etc. — the Flutter equivalent of `node_modules`, always machine-generated, never hand-edited.
2. **Pull dependencies**: `flutter pub get` (grabs audioplayers, home_widget, flutter_local_notifications, etc. from pub.dev).
3. **Wire in the native widget** (this part genuinely can't be auto-generated by `flutter create`, it's hand-written native glue every home_widget project needs):
   - Copy `NightDeckWidgetProvider.kt` → `android/app/src/main/kotlin/com/nightdeck/app/`
   - Copy `nightdeck_widget.xml` → `android/app/src/main/res/layout/`
   - Copy `nightdeck_widget_info.xml` → `android/app/src/main/res/xml/`
   - Paste the contents of `manifest_receiver_snippet.xml` inside the `<application>` tag of the generated `android/app/src/main/AndroidManifest.xml`
4. **Add real audio files** to `assets/sounds/`: `rain.mp3`, `white_noise.mp3`, `ocean.mp3`, `fan.mp3`, `forest.mp3` (filenames must match `lib/models/sound_track.dart`). Any royalty-free ambient loop pack works — I didn't bundle audio since I can't generate real sound files.
5. Launcher icon / app name — cosmetic, do whenever via `flutter_launcher_icons` if you want.

## How the pieces fit together
- **ClockScreen** is the whole app surface — swipe up opens the sound mixer as a bottom sheet, long-press opens Settings. `WakelockPlus` keeps the screen from sleeping while it's the active bedside display.
- **SoundMixerService** runs one looping `AudioPlayer` per track so you can layer sounds (e.g. rain + fan) each at its own volume — that's the actual "mixer" part.
- **NotificationService** schedules a daily repeating local notification at your chosen bedtime using `flutter_local_notifications` + `timezone` (needed for exact-time daily repeats to survive DST correctly).
- **HomeWidgetService** pushes the current time + "now playing" sound name into shared native storage; **NightDeckWidgetProvider** (Kotlin) reads that and renders it into an actual installable Android home/lock-screen widget — this is the "Lock screen widget" milestone.

## Known v0.1 limitations (matches the roadmap's scope)
- iOS widget target (`NightDeckWidget`, referenced in `home_widget_service.dart`) needs an Xcode Widget Extension added manually if you want iOS lock-screen support — Android is the primary target for now.
- No custom clock fonts/skins yet — single AMOLED theme, more skins is a natural v2 add.
- Sound mixer doesn't persist volumes across app restarts yet (only settings/bedtime does, via `shared_preferences`) — quick follow-up if you want it before shipping beta.
